## Intent

提交者可以读取本人任务的私有输出。用合成数据覆盖本人、同组非本人、异组、匿名和伪造身份，验证列表、详情和私有输出的服务端隔离。用测试替身核对取消所有权和跨站请求凭证，实际取消留到 Story 3.1、3.2 联调。

另一标签页退出或切换账号后，清除已显示的任务和私有输出。旧响应晚到或浏览器恢复旧页面时也不得恢复已撤销会话的内容。交付工作区 diff 和实测结果。

</frozen-after-approval>

## Implementation Notes

追溯 FR-01、FR-03、FR-07、FR-08、AD-4、AD-7、AC-11 与 NFR-02 的独立验收。`auth.py` 预置通过独立密码启用的同组合成账号。`submissions.py` 复用账户私有库和 SQLite 快照，通过服务端分配的输出引用授权读取文本。既有库只补建空表，合成输出由测试夹具注入。`app.py` 复用可信会话；测试专用取消入口在写事务内复查同一所有权。`tasks.js` 以浏览器会话范围清理旧画面，并在画面提交前复核。`submission.js` 在登录或退出确认后通知其他标签页。

浏览器可读的页面范围 Cookie 用于快速识别页面所属会话是否变化。可见任务页还会定期通过只读 `GET /api/session` 核对服务端会话和当前页面凭证。收到 `401` 或 `403` 后清空任务和输出，待核对的成功响应须等当前会话检查结束再处理。

从浏览器往返缓存恢复后，任务和输出保持隐藏，直至当前页面收到通过服务端会话校验、且版本达到共享下限的新快照。恢复时重新构建任务卡片。离开页面前发出的私有输出请求即使成功返回，也会被丢弃。
